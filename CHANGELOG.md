# Jharokha changelog

Two version numbers:
- **Web 1.N** — the content and screens. Stamped automatically on every publish (N = publish number). Reaches the TV/phone on next launch.
- **App X.Y (build B)** — the installed Android app. Changes only when the app itself changes; needs a fresh install.

The home screen footer shows both.
