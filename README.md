# Jharokha · झरोखा

A personal all-in-one app for Google TV (and any browser), navigable entirely with a TV remote.

- **Open in a browser:** https://nkotwar.github.io/jharokha/
- **Install on Google TV:** in the *Downloader* app, enter `nkotwar.github.io/jharokha/get`

First app inside: **BG & LC Masterclass** — bank guarantees, letters of credit, UCP 600, Incoterms 2020.

See `CLAUDE.md` for how the project is organised and how to add new apps.
